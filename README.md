## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Vapor World: Over The Mind**. This trainer provides optional gameplay assistance for exploring the dream world, fighting Projections, breaking enemy defenses, extracting embers, and developing forgotten abilities. It is designed for the single-player Windows version and can be used to reduce repetitive difficulty without changing the game's core progression systems.

**Target Audience:** Players who want to explore Vapor World: Over The Mind's story and atmospheric environments with reduced combat difficulty, practice deflection timing, or spend less time repeating difficult encounters.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement options to improve traversal through the game's interconnected dream world. Fast Movement is useful for platforming and backtracking, while Game Speed Control can help with learning enemy timing and navigating hazardous sections.

### Tools & Inventory

Embers are used to reclaim lost powers and strengthen progression, while recovered tools expand what can be done at the workbench. Enable resource options only when needed and avoid changing values during loading screens or cutscenes.

### World & Environment

Vapor World is a seamless surreal environment filled with hidden stories, records, interactive objects, and areas that become accessible as new abilities are recovered. Use the trainer to explore optional paths and investigate locations without repeatedly returning to earlier checkpoints.

### Combat & Weapons

Combat centers on deflecting attacks from Projections. Successful deflections can trigger a unlock Break, exposing an enemy's ember for extraction. Use Invulnerability for safer exploration, Instant unlock Break for practice, and Easy Core Extraction to shorten the vulnerable phase after a successful defense break.
